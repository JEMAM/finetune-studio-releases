## 🌟 O que é o FineTune Studio Local?

O **FineTune Studio** é um aplicativo desktop projetado para simplificar todo o ciclo de vida de LLMs locais:
- 🧪 **Fine-Tuning Descomplicado**: Treine adaptadores LoRA e QLoRA diretamente da interface sem precisar programar scripts de treino complexos.
- 💬 **Chat Dedicado para Modelos Locais**: Converse privadamente com qualquer modelo instalado no seu Ollama (`llama3`, `mistral`, `qwen`, modelos customizados, etc.).
- ⚖️ **Benchmark A/B em Tempo Real**: Compare lado a lado respostas do seu modelo especialista local contra modelos de fronteira em nuvem como o **Google Gemini 3.8**.
- 🧭 **RAG & Espaço 3D**: Visualize seus embeddings em um projetor tridimensional interativo e teste consultas fundamentadas em documentos.
- 📦 **Exportação Automática para Ollama e GGUF**: Converta seus pesos treinados e exporte direto para o catálogo local do seu computador.

## 🚀 Como Instalar

### No Windows:
1. Clique no botão de download acima para baixar o **`FineTuneStudio_1.0.2_x64-setup.exe`**.
2. Dê um duplo clique no arquivo baixado e siga o assistente de instalação.
3. O aplicativo criará automaticamente um atalho na sua **Área de Trabalho** e no **Menu Iniciar**.

### No macOS:
1. Clique no botão de download acima para baixar o **`FineTuneStudio_1.0.0_aarch64.dmg`**.
2. Dê um duplo clique no arquivo `.dmg` baixado.
3. Arraste o ícone do **FineTune Studio** para a pasta **Applications** (Aplicativos).
4. Abra o aplicativo a partir do Launchpad ou pasta de Aplicativos.

> 💡 **Dica**: Certifique-se de ter o [Ollama](https://ollama.com/) instalado no seu computador para usufruir de inferência e chat com modelos locais.

## 🖥️ Requisitos do Sistema

### Windows
- **Sistema Operacional**: Windows 10 ou Windows 11 (64-bit).
- **Processador**: Intel Core i5 / AMD Ryzen 5 ou superior.
- **Memória RAM**: 16 GB recomendado (mínimo 8 GB para modelos leves de 3B).
- **Placa de Vídeo**: GPU NVIDIA com 6 GB+ de VRAM (GTX 1660 / RTX 3060 / 4060 ou superior).

### macOS
- **Sistema Operacional**: macOS 11.0 (Big Sur) ou superior.
- **Processador**: Apple Silicon (chips M1, M2, M3, M4).
- **Memória RAM**: 16 GB de memória unificada recomendada.
- **Aceleração**: Aceleração gráfica nativa via **Apple Metal (MPS)**.

- 🛡️ **Zero envio de dados de treino**: Seus datasets, perguntas de chat e modelos treinados **nunca saem do seu computador**.
